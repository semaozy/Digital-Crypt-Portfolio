# 🌑 Sema Nur Özyılmaz // Digital Crypt & Portfolio

A surrealist, retro-futuristic portfolio.
---

## ⚡ Aesthetic & Architecture

* **Visual Vibe:** CRT scanlines, low-framerate chromatic noise, and a simulated terminal window over a procedural dark canvas.
* **Core Stack:** 
  * **HTML5 / CSS3:** Custom glitch animations, glassmorphism, and responsive retro-terminal styling.
  * **JavaScript (p5.js):** Generates organic, low-fps background digital noise and dynamic vector lines.
* **Architecture:** Zero heavy frameworks. Lightweight, self-contained, and optimized for instant deployment and absolute visual control.

---

## 🛠️ Setup & Execution

To run this encrypted space locally on your machine:

1. Clone or download this repository into your local directory.
2. Open the folder using **VS Code**.
3. Install and run via the **Live Server** extension (Right-click `index.html` -> **"Open with Live Server"**).
4. Access the interactive digital vault directly in your browser.
